🏠 土地なし管理客 週次レポートシステム

Google Apps Script + Claude AI による完全自動化フロー

⏰
STEP 01
自動トリガー起動
毎週木曜日 朝9:00 に Google Apps Script が自動起動。一度 setWeeklyTrigger() を実行するだけで以降は完全自動。
🗓 毎週木曜日 ⏱ 朝9:00 完全自動
📊
STEP 02
スプレッドシートから読み込み
2シートを対象に A〜J 列（10項目）を一括取得。お客様名・フォロー状況・ローン特約期日・各チェックボックスなど。
2026年1月〜（村瀬） 村瀬2025年1月〜
🔍
STEP 03
スマートフィルタリング
複数の条件を組み合わせて「誰を表示するか」を自動判断
🚫A列が濃い灰色の行 → 打ち切り客として除外
✅土地契約チェック済み → フォローリストから除外
🏦ローン期日超過 + 本申込済み → 完了として除外
🚨期日まで14日以内 + 本申込なし → アラート対象
✨
STEP 04
Claude AI でサマリー生成
要注意顧客データを Claude API に送信。「2行・30文字以内・max_tokens:120」の制約でスマホ1画面に収まる簡潔なアドバイスを生成。
Claude claude-opus-4-5 max_tokens: 120
📧
STEP 05
HTML メール送信
統計カード・AIアドバイス・ローンアラート・顧客リスト・進捗バーを <table> レイアウトで組み上げ、GmailApp で送信。
GmailApp table レイアウト 件名にアラート数
