Part 01
はじめに・このシステムで解決したこと
⏱ 約1分

本日は、私が作成した「土地なし管理客 週次レポートシステム」についてご紹介します。

まず、このシステムを作ろうと思ったきっかけからお話しします。

不動産営業では、スプレッドシートでお客様を管理していますが、毎週「誰を今週フォローすべきか」「ローンの期日が迫っているお客様はいないか」を手作業で確認するのは、時間がかかる上に見落とすリスクがありました。

特にローン特約期日は、期限を過ぎると契約が白紙になるリスクがあるため、絶対に見落とせません。

そこで、「毎週自動で、要点だけを届ける」仕組みを作りました。

①

Claude AIでサマリー生成：Anthropic社のAIに今週やるべきことを2行で返してもらいます。
⑤
HTMLメール送信：見やすく整形したレポートをGmailで自動送信します。
⑥
ステージパイプライン：紹介あり→HM契約→土地契約→ローン本申込→決裁案内という5段階で顧客の進捗を管理します。

Part 04
工夫したポイント（ここがメイン！）
⏱ 約4分

今回最も力を入れた工夫ポイントを6つご紹介します。

工夫① 4つのパーツの決め方

なぜメールをこの4つのパーツ構成にしたかについてです。

設計のコンセプトは「開いて5秒で判断できる」でした。忙しい朝に長いレポートを読む時間はありません。そこで情報の優先度を考え、上から「数字→AIの一言→緊急アラート→詳細リスト」の順に並べました。特にローンアラートはAIアドバイスの直下に配置し、最優先で目に入るようにしています。

工夫② 既存の運用を一切変えない設計

スプレッドシートの運用方法を1つも変えていません。

今回は列の並び・チェックボックスの使い方・灰色塗りによる管理方法、すべてそのまま使えるよう、システム側が合わせる設計にしました。

工夫③ 背景色を読み取る打ち切り客の除外

スプレッドシートでは「終了した顧客の行を濃い灰色に塗る」慣習があります。A列の背景色をRGB値として読み取り、グレー系かつ一定の明るさ以下という条件でプログラムが自動判定します。今まで通り灰色に塗るだけで自動除外されます。

工夫④ ローンアラートの精密な3条件判定

ローン特約期日のアラートは、単純に「期日が近い」だけで出すと誤通知が発生します。「もうローン本申込を済ませたのにアラートが出続ける」という問題が実際に起きました。そこで3つの条件を組み合わせました。

🚨 アラートを出す：期日まで14日以内 かつ ローン本申込チェックなし
🔕 アラートを消す：ローン本申込チェックあり → 申込済みなので通知不要
✅ フォローリストから除外：期日超過 かつ 本申込済み → 手続き完了とみなす

必要な人だけにアラートが届く、誤通知ゼロの設計です。

工夫⑤ AIサマリーを「必ず短く返す」仕組み

Claude AIに普通に依頼すると長文が返ってきてスマホで3スクロール分になってしまいました。そこで2段階の制限をかけました。プロンプトで「箇条書き2行のみ・1行は30文字以内・余計な前置き不要」と明記し、さらにmax_tokensを120に制限することで、物理的に長文が返せない設計にしています。

工夫⑥ メールで崩れないtableレイアウト

GmailなどのメールアプリはCSS Grid・Flexboxを正しく解釈できないことがあります。そこで統計カードや顧客カードをすべて昔ながらの<table>タグで構築し直しました。見た目はモダンで美しく、でも裏側は確実に表示される構造です。

Part 05
ぶつかった課題とその解決
⏱ 約1分

開発中に特に苦労した課題を2つご紹介します。

課題①：GASエディタでSyntaxErrorが発生
コードを貼り付けた際に「SyntaxError: Unexpected end of input 行:479」というエラーが出ました。コードが途中で切れた状態で貼り付けられていたことが原因でした。

→ 解決：コードファイル全体を最初から最後まで一括コピーし直し、GASエディタの既存コードをすべて削除してから貼り付ける手順を徹底しました。
課題②：お客様の名前が崩れて表示される
スプレッドシートのセルに全角スペースやセル内改行が混入していて名前が崩れて表示されていました。

→ 解決：cleanName()という関数を作り、全角スペースを半角に変換・改行をスペースに置換・連続スペースを1つにまとめる処理を自動化しました。

今回のシステムで実現できたことを、「3つのゼロ」でまとめます。

✅ システム導入で実現した「3つのゼロ」
①
見落としゼロ：ローン期日や長期未フォローを自動検知。毎週木曜9時に確実に通知が届くため、人間が気にしなくてよくなりました。
②
現場負担ゼロ：既存のスプレッドシートをそのまま使い続けられます。新しい入力ルールも別ツールの学習も一切不要です。
③
判断の迷いゼロ：AIが「今週やること」を2行で提示。出社直後にメールを開けば、その日の最優先アクションがすぐに分かります。

今後の展望としては、フォロー内容をAIが自動記録する機能や、LINE通知への対応なども検討しています。

このシステムの最大の特徴は、「現場の使い方を変えずに、自動化の恩恵だけを受け取れる」点です。

想定Q&A
Q. AIが間違った内容を返したら？
AIサマリーはあくまで参考情報です。詳細はメール下部の顧客カードで確認できるためAIに頼りすぎない設計にしています。
Q. 他のスタッフも使えますか？
GASのCONFIGにメールアドレスを追加するだけで複数人に同時送信できます。
Q. メンテナンスは必要ですか？
列の構成が変わった場合のみCOL定数の修正が必要です。通常運用では手動操作は不要です。
Q. コストはかかりますか？
GAS・Gmailは無料。Claude APIは週1回・120トークン以内の使用であれば月数十円程度です。
