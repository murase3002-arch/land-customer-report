システム概要
毎週木曜日の朝9時に Google Apps Script が自動起動し、スプレッドシートの顧客データを読み込んで分析。 Claude AI（claude-opus-4-5）が今週のアクションを2行で要約し、HTMLメールをGmailで自動送信するシステムです。 打ち切り客の自動除外・ローン特約期日アラート・未フォロー顧客の自動抽出など、営業現場の実務に特化した機能を搭載しています。
