# 土地なし管理客 週次レポート セットアップ手順

## 概要

毎週木曜日に、土地なし管理客スプレッドシートを自動分析して  
Gmailでレポートを送信するシステムです。

```
スプレッドシート → Google Apps Script → Claude AI分析 → Gmail送信
```

---

## Step 1: Google Apps Script を開く

1. スプレッドシートを開く
2. メニュー「**拡張機能**」→「**Apps Script**」をクリック
3. 新しいタブでスクリプトエディタが開く

---

## Step 2: コードを貼り付ける

1. エディタに表示されている既存のコード（`function myFunction() {}`）を**全て削除**
2. `Code.gs` の内容を**全てコピーして貼り付け**
3. 上部の設定を自分の環境に合わせて変更：

```javascript
const CONFIG = {
  SPREADSHEET_ID: 'YOUR_SPREADSHEET_ID',  // ← スプレッドシートのID
  TARGET_SHEETS: ['2026年1月～（村瀬）', '下河'],  // ← 対象シート名
  RECIPIENT_EMAIL: 'your-email@gmail.com', // ← 送信先メールアドレス
  ...
};
```

### スプレッドシートIDの確認方法

スプレッドシートのURLから確認：
```
https://docs.google.com/spreadsheets/d/【ここがID】/edit
```

---

## Step 3: Claude API キーを設定する

セキュリティのため、APIキーはスクリプトプロパティに保存します。

1. スクリプトエディタの左メニュー「**プロジェクトの設定**」をクリック
2. 「**スクリプトプロパティ**」セクションで「**プロパティを追加**」
3. 以下を入力：
   - プロパティ名: `CLAUDE_API_KEY`
   - 値: `sk-ant-...`（実際のAPIキー）
4. 「**保存**」をクリック

> APIキーは https://console.anthropic.com/ で取得できます

---

## Step 4: 動作テストをする

1. エディタ上部の関数選択ドロップダウンで `testRun` を選択
2. ▶ 実行ボタンをクリック
3. 初回は「**権限を確認**」が表示されるので「許可」を選択
4. しばらく待ってGmailに届くか確認

---

## Step 5: 毎週木曜日の自動実行を設定する

1. スクリプトエディタ左メニューの「**トリガー**」（時計アイコン）をクリック
2. 右下「**トリガーを追加**」をクリック
3. 以下のように設定：

| 設定項目 | 値 |
|---------|---|
| 実行する関数 | `weeklyLandCustomerReport` |
| イベントのソース | 時間主導型 |
| 時間ベースのトリガーのタイプ | 週ベースのタイマー |
| 曜日 | 毎週木曜日 |
| 時刻 | 午前9時〜10時 |

4. 「**保存**」をクリック

---

## レポートの内容

毎週木曜日に以下の内容がGmailで届きます：

```
件名: 【土地なし管理客レポート】2026年5月7日（18名）

┌─────────────────────────┐
│  18名  │  5名  │  13名  │
│ 総顧客数 │未フォロー│フォロー済│
└─────────────────────────┘

1. 全体サマリー
   今週の状況を3〜5行で

2. ⚠️ 今週フォローが必要な顧客（優先度順）
   - 田中様：45日間未連絡。春以降検討とのことで今が最適タイミング
   - 山本様：...

3. 📊 顧客ステージ別分析
   ローン特別面談済みが3名、うち...

4. 💡 今週のアクション提案
   1. ...
```

---

## カスタマイズ

### 未フォロー判定日数を変更する

デフォルト: 30日

```javascript
UNFOLLOW_THRESHOLD_DAYS: 30,  // ← 好みの日数に変更
```

### 対象シートを追加する

```javascript
TARGET_SHEETS: ['2026年1月～（村瀬）', '下河', '新しいシート名'],
```

### 送信時刻を変更する

トリガー設定で「午前9時〜10時」の部分を変更してください。

---

## トラブルシューティング

| 症状 | 対処法 |
|------|--------|
| メールが届かない | トリガーが設定されているか確認 |
| 「APIキーがありません」エラー | Step 3を再確認 |
| シートが見つからないエラー | シート名が完全一致しているか確認（全角スペース注意） |
| Gmailの送信上限エラー | 1日100通の上限あり（週1回なので通常問題なし） |
